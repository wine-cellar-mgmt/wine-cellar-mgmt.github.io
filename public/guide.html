처음 시작하기

설치할 것은 없습니다. 링크를 열고 로그인하면 바로 시작됩니다.

  1. 로그인 전달받은 이메일과 임시 비밀번호를 입력합니다.
  2. 비밀번호 바꾸기 오른쪽 위 ⚙️ → 🔑 비밀번호 변경에서 본인만 아는 비밀번호로 바꾸세요. 임시 비밀번호는 계속 쓰지 않는 편이 좋습니다.
  3. 내 셀러 등록 같은 설정 화면의 🍾 내 셀러 관리에서 실제 보관 장소에 맞게 고칩니다. 처음에는 내 셀러 한 개(6칸)만 있습니다. 이름을 바꾸고, 칸 수와 칸당 병 수를 조정한 뒤 셀러 저장을 누르세요. 셀러가 여러 개면 + 셀러 추가로 늘립니다.
  4. 첫 와인 넣기 아래 와인 등록하기를 따라 한 병만 넣어보세요. 감이 금방 옵니다.

📱 휴대폰 홈 화면에 추가하기

앱처럼 쓰려면 브라우저 공유 메뉴에서 홈 화면에 추가를 누르세요. 아이폰은 사파리 공유 → 홈 화면에 추가, 안드로이드는 크롬 ⋮ → 홈 화면에 추가입니다. 주소창 없이 전체 화면으로 열립니다.

와인 등록하기

한 병씩 넣거나, 칸을 통째로 찍어서 한 번에 넣을 수 있습니다.

한 병씩 — + 추가

오른쪽 위 + 추가(휴대폰은 오른쪽 아래 ＋ 동그란 버튼)를 누릅니다.

  1. 이름을 입력하고 🔍를 누릅니다 AI가 웹에서 찾아 생산자·지역·국가·품종·시장가·음용 적기를 자동으로 채워줍니다. 라벨 사진도 같이 찾아옵니다. 이름만 정확히 넣으면 나머지는 대부분 알아서 채워집니다.
  2. 빈티지와 수량 같은 와인을 여러 병 샀으면 수량만 올리면 됩니다. 병마다 따로 등록할 필요 없습니다.
  3. 구매일·구매가격 나중에 통계에서 값어치 변화를 보려면 구매가를 넣어두는 게 좋습니다. 몰라도 그냥 비워두면 됩니다.
  4. 셀러와 칸 번호 실제로 넣어둔 자리를 고릅니다. 이게 정확해야 나중에 병을 찾을 수 있습니다.
  5. 추가 끝입니다. 매그넘 같은 큰 병이면 병 용량도 바꿔주세요.

여러 병 한꺼번에 — 📷 일괄 입력

칸 하나를 통째로 정리할 때 훨씬 빠릅니다.

  1. 셀러와 칸 번호를 고릅니다 한 번에 한 칸씩 진행합니다.
  2. 라벨이 보이게 사진을 찍습니다 여러 병이 한 장에 같이 나와도 됩니다. 여러 장을 올려도 됩니다.
  3. AI가 라벨을 읽어 목록을 만듭니다 이름·빈티지를 알아서 인식합니다.
  4. 검토하고 고칩니다 잘못 읽은 이름은 직접 수정하세요. 여기서 가격 검색을 돌리거나 사진을 교체할 수도 있습니다.
  5. 전체 추가 목록에 있는 와인이 한 번에 등록됩니다.

💡 사진이 잘 안 읽힐 때

라벨에 빛이 반사되거나 비스듬히 찍히면 인식률이 떨어집니다. 정면에서, 밝은 곳에서, 라벨 글씨가 또렷하게 나오도록 찍으면 훨씬 잘 읽습니다. 그래도 틀리면 검토 화면에서 고치면 되니 완벽하게 찍으려고 애쓸 필요는 없습니다.

마신 기록 남기기

기록을 남기면 셀러에서 병이 자동으로 빠집니다. 나중에 통계와 취향 파악에 쓰입니다.

한 병 마셨을 때

셀러 뷰나 검색에서 와인을 찾아 🍷 마심을 누릅니다. 마신 날짜 · 자리/특별한 날 · 함께한 사람 · 평점 · 한마디를 남길 수 있습니다. 사진도 넣을 수 있고, 전부 선택 사항이라 날짜만 확인하고 저장해도 됩니다.

여러 병을 한 자리에서 마셨을 때

셀러 뷰에서 병 왼쪽의 체크박스로 여러 개를 고르면 위에 툴바가 나타납니다. 🥂 선택한 N병 함께 마심을 누르면 날짜·함께한 사람·자리는 한 번만 입력하고, 평점과 한마디는 병마다 따로 남길 수 있습니다. 한 모임에서 여러 병을 딴 날 편합니다.

🗄 서로 다른 셀러의 와인을 함께 마셨다면

셀러 뷰에서 셀러 탭을 옮겨도 선택은 그대로 유지됩니다. 1번 셀러에서 몇 병 고르고, 2번 셀러 탭으로 넘어가 더 고르는 식으로 여러 셀러의 병을 함께 담을 수 있습니다. 위 툴바에 이 셀러 N · 다른 셀러 M으로 표시되고, 🥂 선택한 N병 함께 마심 버튼에는 (3개 셀러)처럼 셀러 수가 붙습니다.

📋 전체 목록 탭에서도 똑같이 됩니다. 이쪽은 전체 셀러가 한 화면에 나오므로 병이 많을 때 훑어가며 고르기 편합니다.

입력 창에는 병마다 어느 셀러 몇 번 칸에서 꺼낸 병인지 같이 나오고, 저장된 음주 기록에도 그대로 남습니다.

⚠️ 일괄 마심으로 안 되는 두 가지

같은 와인 여러 병 — 목록에서 수량 3인 항목은 체크를 한 번밖에 못 하고 1병만 빠집니다. 3병을 마셨다면 그 와인만 🍷 마심을 3번 눌러주세요.

위스키·증류주(바이주·전통주 포함) — 병을 따고 여러 번 나눠 마시는 술이라 잔량 %를 남기는 시음 기록 방식이어서 일괄 마심에서는 빠집니다. 버튼 아래에 위스키 N종은 제외라고 표시되며, 이 술들은 각각 🥃 시음으로 기록해주세요.

밖에서 마셨을 때

내 셀러에 없는 와인도 기록할 수 있습니다. 📖 음주 기록 탭의 📷 밖에서 마신 와인 기록을 누르세요. 라벨 사진을 올리면 AI가 이름을 읽어줍니다. 식당이나 남의 집에서 마신 와인이 재고에 영향을 주지 않고 기록만 남습니다.

⚠️ 기록을 지우면

음주 기록 삭제는 기록만 지웁니다. 이미 빠진 병이 셀러로 돌아오지는 않습니다. 실수로 마심 처리했다면 그 와인을 다시 등록해주세요.

옮기고 고치기

와인을 누르면 상세 화면이 열립니다. 여기서 대부분의 관리가 이뤄집니다.

하고 싶은 것방법
정보 고치기✏️ 수정 — 이름, 빈티지, 가격, 메모 등
자리 옮기기🚚 위치 이동 — 옮길 셀러·칸과 병 수를 고릅니다
병 지우기삭제 — 마시지 않고 없앨 때(선물 등)
여러 개 한 번에 지우기전체 목록이나 셀러 뷰에서 체크 후 🗑 선택 삭제
여러 개 한 번에 마심셀러 뷰나 📋 전체 목록에서 체크 후 🥂 선택한 N병 함께 마심 — 셀러가 달라도 됩니다

💡 3병 중 1병만 옮기기

위치 이동에서 이동할 병 수를 1로 하면 1병만 옮겨가고 원래 자리에 2병이 남습니다. 옮긴 자리에 같은 와인이 이미 있으면 자동으로 합쳐집니다.

찾아보기

검색은 이름만이 아니라 여러 정보를 한꺼번에 훑습니다.

🔍 검색에 입력하면 이름·생산자·지역·국가·품종·빈티지·메모에서 찾습니다. 한글로 쳐도 됩니다 — 까베르네, 부르고뉴, 샴페인처럼 익숙한 한글 표기로 검색해도 영문 이름의 와인이 나옵니다.

  • 2018 — 해당 빈티지
  • 매그넘 — 큰 병만
  • 선물 — 메모에 그렇게 적어둔 와인

목록을 표로 훑어보려면 📋 전체 목록이 낫습니다. 이름순·빈티지순·구매가순·시장가순으로 정렬하고 셀러별로 걸러볼 수 있습니다.

음용 적기와 통계

⏰ 음용 적기

빈티지와 와인 종류를 바탕으로 지금 마시기 좋은지를 판단해 보여줍니다. 빨리 마셔야 → 지금 절정 → 마시기 좋음 → 곧 절정 → 숙성 중 순으로 정렬됩니다. 맨 위에 있는 와인부터 비우면 놓치는 병이 줄어듭니다.

정보가 부족해 판단이 안 되는 와인은 🔮 음용시기 추정으로 AI에게 물어볼 수 있습니다.

📊 통계

타입·국가·지역별 분포와 함께, 구매가와 현재 시장가를 비교한 컬렉션 가치를 보여줍니다. 구매가와 시장가가 둘 다 입력된 와인만 비교에 들어갑니다. 그래서 등록할 때 구매가를 넣어두면 나중에 볼거리가 많아집니다.

⚠️ 와인이 든 셀러는 지울 수 없습니다

안에 든 와인이 갈 곳을 잃기 때문입니다. 셀러를 없애거나 칸 수를 줄이려면 그 자리의 와인을 먼저 다른 곳으로 옮기세요.

위스키·증류주

기본은 꺼져 있습니다. 위스키나 다른 술도 함께 관리하고 싶을 때만 켜세요.

⚙️ 설정 → 🥃 위스키 기능 토글을 켜면 됩니다. 켜는 순간 와인 추가와 일괄 입력 화면에 🍷 와인 / 🥃 위스키 선택이 생깁니다. 위스키뿐 아니라 진·럼·데킬라·포트 같은 술도 여기로 관리합니다.

와인과 다른 점

차이
빈티지 대신숙성연수와 도수를 입력합니다 (NAS면 숙성연수는 비워두세요)
기본 용량700ml (와인은 750ml)
음용 적기해당 없음 — 위스키는 이 탭에 나오지 않습니다

가장 큰 차이 — 한 병을 여러 번에 걸쳐 마십니다

와인은 한 번 따면 그 병이 끝나지만 위스키는 아닙니다. 그래서 기록 방식이 다릅니다.

위스키에서는 🥃 시음을 누르면 병이 줄어들지 않습니다. 대신 마신 후 잔량 슬라이더로 남은 양을 %로 기록합니다. 첫 기록을 남기면 개봉일이 자동으로 잡히고, 그 뒤로는 마실 때마다 잔량만 갱신하면서 시음 기록이 쌓입니다. 한 병을 두고 몇 달에 걸쳐 마신 흐름이 그대로 남습니다.

병을 다 비웠다면 기록할 때 빈 병에 체크하세요. 그때 비로소 병 수가 하나 줄어듭니다. 같은 위스키가 여러 병 있으면 남은 병은 미개봉 상태로 초기화됩니다.

🥃 개봉 배지

목록과 셀러 화면에서 개봉한 위스키에는 🥃 개봉 55%처럼 남은 양이 표시됩니다. 어떤 병이 열려 있고 얼마나 남았는지 한눈에 보입니다.

위스키를 안 쓰기로 했다면 토글을 다시 끄면 됩니다. 이미 등록한 위스키 기록은 지워지지 않고 그대로 보관되며, 다시 켜면 돌아옵니다.

알아두면 좋은 것

🔒 내 와인은 나만 봅니다

계정마다 데이터가 완전히 분리되어 있습니다. 같은 앱을 쓰는 다른 사람의 와인은 서로 보이지 않습니다.

💾 저장 버튼이 따로 없습니다

추가·수정·마심은 누르는 즉시 서버에 저장됩니다. 다른 기기에서 로그인해도 그대로 이어집니다. 휴대폰으로 등록하고 PC에서 정리하는 식으로 써도 됩니다.

🔄 화면이 이상하면 새로고침

앱이 업데이트됐는데 화면이 그대로면 Ctrl+Shift+R(맥은 ⌘+Shift+R)로 강력 새로고침하세요. 휴대폰은 브라우저를 완전히 닫았다 다시 열면 됩니다.

✍️ 메모를 적극적으로 쓰세요
